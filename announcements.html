Redemption Has Relaunched!
Relaunch
2026-03-31  |  Admin

After a period of downtime, Redemption is back online and actively developed. The server is live, the world is open, and new content is already in place.

Whether you're a returning veteran or a brand new player, now is the best time to log in. The relaunch has brought with it a wave of updates including a full overhaul of the metallic dragon population and a completely rebuilt elemental wheel system.

The development team is committed to regular updates. Expect balance changes, new content, and ongoing improvements. Check this page regularly — or keep an eye on the in-game news board for real-time updates.

Metallic Dragon Overhaul
Major Update
2026-03-28  |  Admin

The metallic dragons have been completely rebuilt. Previously placeholder-level content, they are now fully realized threats — and allies, depending on your choices.

What Changed

  • All metallic dragon types (Gold, Silver, Bronze, Copper, Brass) have been revamped with new stat profiles
  • New ability sets — each dragon type now has distinct, lore-appropriate abilities
  • Updated loot tables with unique metallic dragon drops
  • New dialogue and quest hooks tied to the metallic dragon faction
  • Metallic dragon lairs redesigned for better encounter flow

These dragons are connected to the larger lore of the Dragon resurgence in Dominia. Expect them to play a bigger role in upcoming content.

New Elemental Wheel System
System Rework
2026-03-25  |  Admin

The elemental system powering all magical combat in Redemption has been rebuilt from the ground up. This is one of the most significant mechanical changes to the game in years.

Key Changes

  • All elemental types have been rebalanced with true strengths and weaknesses
  • Element interactions are now consistent and documented — see help elements in-game
  • Shadow element added as a distinct damage type (previously folded into other categories)
  • Holy element has been reworked — interactions with Shadow are now a meaningful strategic axis
  • New resist and vulnerability messaging in combat to help players learn the system

If you played before the relaunch, your existing knowledge of the elemental system may be outdated. We recommend reviewing the help files for the current element chart.

Balance Pass — Warrior & Mage Paths
Balance
2026-03-20  |  Admin

A targeted balance pass was applied to several warrior-path skills and mage-path spells following the elemental wheel rework.

  • Bash skill cooldown slightly reduced at high proficiency
  • Fireball base damage adjusted upward to match the new elemental scaling
  • Mana cost for several low-level spells reduced to be more new-player friendly
  • Several mob resistances adjusted to align with the new elemental wheel

Further balance adjustments will follow as we gather player feedback. Reach out in-game via gossip or tell an immortal if you notice something that feels off.
